# Аналіз приватності MiniBrowser: що WebView розкриває і що можна обмежити

| Дані / сигнал | Що бачить сайт | Що робить MiniBrowser | Чому саме так |
|---|---|---|---|
| Сторонні запити, трекери, реклама | Усі запити сторінки | Блок за EasyList, EasyPrivacy, URLhaus; рівень «Суворий» блокує всі сторонні скрипти, iframe, XHR/fetch, object | `shouldInterceptRequest`; не бачить POST-тіл, WebSocket, частину Service Worker; тип ресурсу — евристика |
| Cookie | Свої та сторонні | Сторонні вимкнено за налаштуванням або суворим рівнем (per-tab, залежно від сайту); перегляд/видалення | `CookieManager` не повідомляє про окремі відхилені cookie |
| localStorage / IndexedDB / WebSQL | Свої | Очищення сайту вручну; на суворому рівні — автоматично після виходу з сайту чи закриття вкладки | `WebStorage.deleteOrigin`; переліку origin публічний API не дає |
| Ізоляція сесій | — | Приватні вкладки в окремому профілі WebView (`MULTI_PROFILE`); без нього — чесне попередження | Потрібен WebView 128+ |
| Протокол | http/https | Авто-https; http лише за явним підтвердженням | Захист від циклів перенаправлень |
| Дозволи (камера, мікрофон, геолокація) | Запити | Діалог, запам'ятовування, відкликання, пер-сайтовий менеджер | Сповіщення WebView не підтримує |
| Canvas / WebGL / аудіо / пристрої / батарея | Значення API | Блок відомих скриптів; детектор показує спроби | Підміна API свідомо **не** робиться |
| User-Agent, Client Hints, мова, часовий пояс, екран | Передаються | Не змінюються; екран «Що бачать сайти» показує реальні значення | Підміна = обман сайтів, ламає їх і суперечить принципу чесних сигналів |
| IP-адреса | Видна серверу й оператору | Нічого | Лише VPN |
| Referer | За Referrer-Policy сайту | Нічого | WebView не дає змінювати заголовок |
| Видимість вкладки, focus/blur | Справжні події | **Не підміняються та не приховуються** | Принципова відмова: це був би обхід систем контролю |

## Рівні захисту сайту
`Вимкнено` — без блокування (для сумісності), `Стандартний` — налаштування розділу «Приватність», `Суворий` — див. вище. Рівень за замовчуванням і рівень окремого сайту (за зареєстрованим доменом) задаються в панелі приватності та в налаштуваннях.
